# 카운터사이드 웹뷰어
카운터사이드에 관한 여러 정보,기능이 구현된 아카이브 웹사이트입니다.
아직 개발중입니다.
### [counterside.kro.kr](counterside.kro.kr)

## 구현된 기능

* 스토리 뷰어

* 각종 스파인 뷰어

* 음원 재생기

* 미니게임 3종
  * 나이엘의 검술 훈련
  * 탕비실 침공작전
  * 카페 스트레가
 
* 정보 DB
  * 사원
  * 함선
  * 오퍼레이터
  * 장비
  * 엠블럼
  * 칭호
  * 프레임
  * 트로피

* 공식 채널 백업
  * 공식 웹페이지
  * 공식 네이버 라운지

## 주의사항
웹페이지 제작에는 ChatGPT가 사용되었습니다.

이 웹페이지, 리포지토리는 자료를 소유, 권리를 주장하지 않습니다. 모든 권리는 Studiobside Co., Ltd에게 있습니다
